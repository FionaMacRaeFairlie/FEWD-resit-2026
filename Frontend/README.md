# Starter code for FEWD resit coursework

This app provides a front end interface for a family organiser
It is expected that the application will allow

- users to register with the app and to log in
- logged in users should be able to
- browse details of current and upcoming events for their family
- search and filter events
- add events
- amend and delete events they have created
- users should not be able to view information from different family groups

## This app provides some of the required functionality

However the authentication does not work correctly. User can add themselves to any family and allocate themselves administrator rights. Duplicate users can also be added to the application
